# Сайт на своём домене (VPS) + онлайн-оплата СБП

Краткая версия. Подробности — в Word-файлах:
- `Инструкция-сайт-и-оплата-для-нас.docx` — для владельца (что оформить, сколько стоит, чек-лист).
- `ТЗ-VPS-и-оплата-для-Cowork.docx` — техзадание с командами и кодом для кодинг-агента.

## Часть 1. Сайт на VPS под доменом

1. Купить домен (reg.ru, nic.ru) и VPS с **Ubuntu 22.04/24.04** (Timeweb Cloud, Selectel, Beget).
2. В панели домена прописать A-записи `@` и `www` на IP сервера.
3. Подключиться: `ssh root@IP`.
4. Поставить веб-сервер и PHP:
   ```bash
   apt update && apt upgrade -y
   apt install -y nginx php-fpm php-curl git ufw
   ufw allow OpenSSH && ufw allow 'Nginx Full' && ufw --force enable
   ```
5. Залить сайт в `/var/www/site` (git clone или scp), права:
   ```bash
   chown -R www-data:www-data /var/www/site
   ```
6. Настроить nginx (`/etc/nginx/sites-available/site`), включить сайт:
   ```bash
   ln -s /etc/nginx/sites-available/site /etc/nginx/sites-enabled/
   rm -f /etc/nginx/sites-enabled/default
   nginx -t && systemctl reload nginx
   systemctl enable nginx php8.1-fpm      # версию PHP смотреть в ls /run/php/
   ```
7. Бесплатный HTTPS:
   ```bash
   apt install -y certbot python3-certbot-nginx
   certbot --nginx -d ДОМЕН.ru -d www.ДОМЕН.ru
   certbot renew --dry-run
   ```

HTTPS обязателен — без него платёжные сервисы не работают.

## Часть 2. Приём денег (легально в РФ)

**Сам сайт деньги не принимает** — их принимает платёжный сервис. Карту клиент вводит
на его защищённой странице, а не на нашем сайте.

1. **Статус:** самозанятый (через «Мой налог», касса не нужна) или ИП (нужна онлайн-касса).
2. **Счёт:** ИП — расчётный счёт в банке; самозанятому хватит карты.
3. **Чек 54-ФЗ:** самозанятый — автоматически в «Мой налог»; ИП — онлайн-касса
   (часто идёт в комплекте с платёжным сервисом).
4. **Платёжный сервис:** ЮKassa (карты + СБП + касса), Т-Касса (Тинькофф),
   Robokassa (работает с самозанятыми) или СБП напрямую через банк (самая низкая комиссия).
   После модерации получаете `shopId` и `secretKey`.

## Часть 3. Подключение оплаты к сайту

Поток: клиент жмёт «Оплатить» → `POST /api/create-payment.php` создаёт платёж в ЮKassa →
получаем `confirmation_url` → редирект → **на телефоне выбор банка (СБП), на ПК QR** →
клиент платит в приложении банка → возврат на `success.html` + вебхук `payment.succeeded`.

Файлы на сервере:
- `api/config.php` — ключи (закрыт от веба правилом nginx, не в git)
- `api/create-payment.php` — создание платежа
- `api/webhook.php` — автоподтверждение оплаты (всегда отвечает 200)
- `success.html` — страница «оплачено»

Полный код всех файлов и конфиг nginx — в `ТЗ-VPS-и-оплата-для-Cowork.docx`.
