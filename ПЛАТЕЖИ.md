# Как подключить реальную онлайн-оплату (легально, в РФ)

Короткая правда: **сам сайт не имеет права принимать номер карты и списывать деньги.**
Это требует сертификации PCI DSS и лицензии. Поэтому у всех нормальных магазинов
оплату проводит **платёжный сервис (эквайер)**, а сайт только отправляет туда заказ.
Наш сайт уже сделан правильно: онлайн-оплата идёт через **СБП по QR**, карту на сайте
никто не вводит.

Чтобы деньги реально приходили — нужно пройти 5 шагов.

---

## Шаг 1. Оформить статус (без него платёжку не подключить)

| Статус | Кому подходит | Плюсы | Минусы |
|--------|---------------|-------|--------|
| **Самозанятый (НПД)** | мелкие продажи своими руками (мамино кафе, рукоделие) | оформление за 10 мин в приложении «Мой налог», налог 4–6%, не нужна касса | нельзя нанимать сотрудников и перепродавать чужой товар |
| **ИП** | магазин, кафе с доставкой, перепродажа | можно всё, любой эквайринг, сотрудники | нужна онлайн-касса, взносы |
| **ООО** | если несколько владельцев / крупно | максимум возможностей | сложнее и дороже |

Для **«мамино кафе с доставкой»** обычно берут **самозанятость** (если готовит сама и без
наёмных) или **ИП** (если есть сотрудники/точка). Оформляется онлайн через «Мой налог»
или банк (Тинькофф/Сбер/Точка открывают ИП бесплатно).

## Шаг 2. Открыть расчётный счёт

В любом банке для бизнеса (Тинькофф, Сбербизнес, Точка, Альфа). На него будут приходить
деньги от эквайера. Самозанятому достаточно обычной карты, привязанной к «Мой налог».

## Шаг 3. Онлайн-касса и чек (54-ФЗ)

По закону покупателю нужно выдать **фискальный чек**.
- **Самозанятый** — чек формируется автоматически в приложении «Мой налог» (касса не нужна).
- **ИП/ООО** — нужна **онлайн-касса**. Проще всего облачная: **АТОЛ Онлайн, Модулькасса,
  ЮKassa-касса, Lifepay** — они сами шлют чек в налоговую и покупателю. Платёжные сервисы
  ниже часто дают кассу «в комплекте».

## Шаг 4. Выбрать платёжный сервис (эквайер)

Иностранные (Stripe, PayPal) в РФ не работают. Рабочие варианты:

| Сервис | Чем хорош | Комиссия* |
|--------|-----------|-----------|
| **ЮKassa** (Яндекс) | самый популярный, простая интеграция, касса в комплекте, СБП, карты | ~2.8% карты / ~0.4–0.7% СБП |
| **Т-Касса** (Тинькофф) | отличное API, быстрая выплата, СБП | ~2.3–2.8% / СБП дешевле |
| **Robokassa** | работает и с **самозанятыми**, простая ссылка на оплату | ~3.5% |
| **СБП через банк** | самая низкая комиссия, QR-код | ~0.4–0.7% |

\* комиссии ориентировочные, уточняйте в кабинете.

**Совет:** для старта — **ЮKassa** (карты + СБП + чек) или чистый **СБП от банка**
(минимальная комиссия, как сделано у нас).

## Шаг 5. Подключить к сайту

Есть два пути.

### Вариант А — без программирования (проще всего для старта)
1. В кабинете эквайера/банка создаёте **платёжную ссылку** или **статический СБП-QR**.
2. QR/ссылку показываете покупателю на шаге оплаты (у нас для этого уже есть блок «Оплата по QR»).
3. Клиент платит в приложении банка → деньги падают на счёт, чек уходит автоматически.
   Подтверждение заказа делаете вручную (увидели поступление — собрали заказ).

> Идеально для «мамино кафе»: ноль кода, ноль сервера, всё легально.
> Минус — сумма и статус оплаты не подставляются автоматически.

### Вариант Б — «по-взрослому», с автоподтверждением (наш сайт на Vercel это поддержит)
Нужна **одна серверлес-функция** (Vercel Functions / Netlify Functions — бесплатно):

1. Регистрируетесь в **ЮKassa**, получаете `shopId` и `secretKey`.
2. Создаёте файл `api/create-payment.js` (пример для Vercel):

   ```js
   // api/create-payment.js  — секретный ключ живёт ТОЛЬКО на сервере
   export default async function handler(req, res) {
     const { amount, orderId, email } = req.body;
     const auth = Buffer.from(`${process.env.YOOKASSA_SHOP_ID}:${process.env.YOOKASSA_SECRET}`).toString('base64');
     const r = await fetch('https://api.yookassa.ru/v3/payments', {
       method: 'POST',
       headers: {
         'Authorization': `Basic ${auth}`,
         'Idempotence-Key': orderId,
         'Content-Type': 'application/json',
       },
       body: JSON.stringify({
         amount: { value: amount, currency: 'RUB' },
         capture: true,
         confirmation: { type: 'redirect', return_url: 'https://ВАШ-САЙТ/success.html' },
         description: `Заказ №${orderId}`,
         receipt: { customer: { email }, items: [/* позиции для чека 54-ФЗ */] },
       }),
     });
     const data = await r.json();
     res.json({ url: data.confirmation.confirmation_url }); // ссылка на оплату
   }
   ```

3. Ключи кладёте в **переменные окружения Vercel** (`YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET`) —
   в код их писать нельзя.
4. На кнопку «Оплатить» вешаете вызов:

   ```js
   const r = await fetch('/api/create-payment', {
     method: 'POST', headers: { 'Content-Type': 'application/json' },
     body: JSON.stringify({ amount: total, orderId: order.no, email: user.email }),
   });
   const { url } = await r.json();
   window.location = url;           // редирект на защищённую страницу ЮKassa
   ```

5. ЮKassa показывает **свою** страницу оплаты (карта/СБП/SberPay), списывает деньги,
   отправляет чек и возвращает клиента на `success.html`.
6. Для 100% надёжности добавляете **вебхук** `api/yookassa-webhook.js` — ЮKassa сама
   сообщает «оплата прошла», и вы помечаете заказ оплаченным.

---

## Итого — что осталось сделать, чтобы оплата стала «боевой»

1. [ ] Оформить самозанятость или ИП + расчётный счёт.
2. [ ] Настроить чек: «Мой налог» (самозанятый) или облачную кассу (ИП).
3. [ ] Зарегистрироваться в ЮKassa / подключить СБП-QR в банке.
4. [ ] Простой старт: вставить реальный СБП-QR/ссылку в блок оплаты.
5. [ ] Полный автомат: добавить серверлес-функцию `api/create-payment` + ключи в env + вебхук.
6. [ ] Переключить сервис из тестового режима в боевой.

После этого деньги будут приходить на счёт **легально и автоматически**.
