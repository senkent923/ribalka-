# Онлайн-оплата через СБП на сайте (РФ) — техническое задание для кодинг-агента

> Это готовое ТЗ. Отдай его своему ИИ-агенту (Cowork / Claude Code) —
> он реализует рабочую онлайн-оплату. Всё легально и под РФ.
> Подходит для любого сайта: кафе с доставкой, магазин и т.д.

---

## 0. Как это должно работать (важно про телефон)

СБП работает через **платёжную ссылку**, а не только QR:

- **На компьютере** — показываем **QR-код**, покупатель сканирует телефоном.
- **На телефоне** — кнопка «Оплатить» **открывает выбор банка** (СБП), человек тапает
  свой банк → открывается приложение банка → подтверждает оплату. **Сканировать ничего не надо.**

Это поведение даёт сам платёжный сервис (ЮKassa / Т-Касса): при переходе на его страницу
оплаты он определяет устройство и показывает либо QR (десктоп), либо список банков (телефон).
Нам нужно лишь **создать платёж на сервере и перекинуть клиента на эту страницу.**

Схема:
```
Клиент жмёт «Оплатить»
      → наш сервер (serverless-функция) создаёт платёж в ЮKassa
      → получаем ссылку confirmation_url
      → редиректим клиента на эту ссылку
      → ЮKassa показывает: ПК → QR СБП, телефон → выбор банка
      → клиент платит в приложении банка
      → деньги падают на счёт продавца, чек уходит в налоговую
      → ЮKassa возвращает клиента на success.html и шлёт вебхук «оплачено»
```

Карту на нашем сайте **никто не вводит** — это и безопасно, и требование закона.

---

## 1. Что нужно получить заранее (без кода)

1. **Статус:**
   - **Самозанятый** — если готовит/делает сам, без сотрудников (оформить в приложении «Мой налог»).
   - **ИП** — если есть сотрудники/точка/перепродажа (открывают бесплатно Тинькофф, Сбер, Точка).
2. **Расчётный счёт** в банке для бизнеса (самозанятому — карта в «Мой налог»).
3. **Аккаунт в платёжном сервисе** с поддержкой СБП:
   - **ЮKassa** — рекомендуется (карты + СБП + онлайн-касса 54-ФЗ в комплекте).
   - или **Т-Касса** (Тинькофф), или **Robokassa** (работает с самозанятыми).
   После регистрации и модерации получите **два ключа**: `shopId` и `secretKey`.
4. **Онлайн-касса (54-ФЗ)** для чека:
   - самозанятый — чек формируется автоматически в «Мой налог»;
   - ИП — подключить кассу (ЮKassa даёт кассу «в комплекте», либо АТОЛ Онлайн / Модулькасса).

## 2. Стек

- Фронтенд — любой (статический сайт, React, обычный HTML).
- Хостинг с **serverless-функциями**: **Vercel** (бесплатно) или Netlify.
  Секретный ключ должен жить **только на сервере**, не в коде фронта.

## 3. Реализация (полный код, пример для ЮKassa + Vercel)

### 3.1. Серверная функция создания платежа

Создай файл `api/create-payment.js`:

```js
// api/create-payment.js
// Создаёт платёж в ЮKassa и возвращает ссылку на оплату (СБП + карты).
export default async function handler(req, res) {
  if (req.method !== 'POST') return res.status(405).json({ error: 'Method not allowed' });

  try {
    const { amount, orderId, email, items } = req.body; // amount: строка "1250.00"
    const shopId = process.env.YOOKASSA_SHOP_ID;
    const secret = process.env.YOOKASSA_SECRET_KEY;
    const auth = Buffer.from(`${shopId}:${secret}`).toString('base64');

    const response = await fetch('https://api.yookassa.ru/v3/payments', {
      method: 'POST',
      headers: {
        'Authorization': `Basic ${auth}`,
        'Idempotence-Key': `${orderId}-${Date.now()}`, // защита от двойного списания
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        amount: { value: amount, currency: 'RUB' },
        capture: true,
        // Способ оплаты по умолчанию — СБП. Убери payment_method_data,
        // если хочешь дать выбор «СБП или карта».
        payment_method_data: { type: 'sbp' },
        confirmation: {
          type: 'redirect',
          return_url: `${process.env.SITE_URL}/success.html?order=${orderId}`,
        },
        description: `Заказ №${orderId}`,
        // Чек 54-ФЗ (для ИП/ООО). Для самозанятого чек делает «Мой налог».
        receipt: {
          customer: { email: email || 'client@example.com' },
          items: (items || []).map((it) => ({
            description: it.name.slice(0, 128),
            quantity: String(it.qty),
            amount: { value: (it.price).toFixed(2), currency: 'RUB' },
            vat_code: 1,               // без НДС (уточни свой режим)
            payment_mode: 'full_payment',
            payment_subject: 'commodity',
          })),
        },
      }),
    });

    const data = await response.json();
    if (!data.confirmation || !data.confirmation.confirmation_url) {
      return res.status(400).json({ error: 'Не удалось создать платёж', details: data });
    }
    // ссылка, на которую редиректим клиента (там будет QR на ПК / выбор банка на телефоне)
    return res.status(200).json({ url: data.confirmation.confirmation_url, id: data.id });
  } catch (e) {
    return res.status(500).json({ error: e.message });
  }
}
```

### 3.2. Кнопка оплаты на фронтенде

На шаге оформления заказа, при нажатии «Оплатить»:

```js
async function payOnline(order) {
  const res = await fetch('/api/create-payment', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      amount: order.total.toFixed(2),   // "1250.00"
      orderId: order.no,
      email: order.email,
      items: order.items,               // [{name, qty, price}]
    }),
  });
  const data = await res.json();
  if (data.url) {
    window.location.href = data.url;    // → страница ЮKassa (QR или выбор банка)
  } else {
    alert('Ошибка оплаты, попробуйте ещё раз');
  }
}
```

### 3.3. Страница «оплата прошла»

Создай `success.html` — простую страницу «Спасибо, заказ оплачен».
ЮKassa вернёт сюда клиента после оплаты.

### 3.4. Вебхук (подтверждение оплаты автоматически)

Создай `api/webhook.js` — ЮKassa сама сообщит, что деньги пришли:

```js
// api/webhook.js
export default async function handler(req, res) {
  const event = req.body;
  if (event.event === 'payment.succeeded') {
    const orderId = event.object.description; // «Заказ №...»
    // TODO: пометить заказ оплаченным в своей базе/таблице, уведомить кухню
    console.log('Оплачен:', orderId, event.object.amount.value, '₽');
  }
  res.status(200).json({ ok: true }); // обязательно ответить 200
}
```

В кабинете ЮKassa в разделе «HTTP-уведомления» укажи адрес:
`https://ВАШ-САЙТ/api/webhook` и событие `payment.succeeded`.

## 4. Ключи и переменные окружения

В настройках проекта на Vercel (Settings → Environment Variables) добавь:

```
YOOKASSA_SHOP_ID   = <shopId из кабинета ЮKassa>
YOOKASSA_SECRET_KEY= <секретный ключ из кабинета ЮKassa>
SITE_URL           = https://ваш-домен
```

**Секретный ключ в код НЕ вписывать** — только в переменные окружения.

---

## 5. Порядок запуска

1. Зарегистрировать самозанятость/ИП + счёт.
2. Создать аккаунт ЮKassa, пройти модерацию, получить `shopId` и `secretKey`.
3. Настроить чек (самозанятый — «Мой налог»; ИП — касса в ЮKassa).
4. Добавить в проект файлы `api/create-payment.js`, `api/webhook.js`, `success.html`.
5. Прописать переменные окружения на Vercel.
6. Повесить кнопку «Оплатить» на функцию `payOnline`.
7. Указать адрес вебхука в кабинете ЮKassa.
8. Протестировать в **тестовом режиме** ЮKassa (тестовые карты/СБП).
9. Переключить магазин в **боевой режим** — всё, деньги приходят на счёт.

---

## 6. Если совсем без кода (быстрый старт)

Можно вообще без сервера:
1. В банке/ЮKassa создать **платёжную ссылку** (готовая ссылка на оплату фикс. суммы)
   или **статический СБП-QR**.
2. На телефоне ссылка открывает выбор банка, на ПК показывает QR.
3. Минус — сумма/подтверждение не автоматические (подходит для маленького кафе).
   Для полноценного магазина лучше вариант с кодом выше.

## 7. Альтернативы ЮKassa

- **Т-Касса (Тинькофф)** — аналогичный API (`https://securepay.tinkoff.ru/v2/Init`),
  тоже отдаёт `PaymentURL` для редиректа (СБП + карты).
- **Robokassa** — проще, работает с самозанятыми, оплата по подписанной ссылке.
- **Чистый СБП через банк** — самая низкая комиссия, банк даёт ссылку/QR (`qr.nspk.ru/...`).

Схема везде одинаковая: **сервер создаёт платёж → редирект на страницу оплаты →
на телефоне выбор банка, на ПК QR → деньги на счёт → вебхук подтверждает.**
