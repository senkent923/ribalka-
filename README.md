# 🎣 РЫБОЛОВ — рыболовный магазин-каталог (Санкт-Петербург)

Сайт-каталог снастей для рыбалки. Покупатель выбирает спиннинг, катушку,
леску, воблер или другую снасть, изучает характеристики и оформляет заказ.
Магазин находится в **Санкт-Петербурге** (Лиговский пр-т, 50).

## Дизайн

Премиальная тёмная тема в стиле рыбалки: **тёмно-зелёный + чёрный** с
изумрудным акцентом. Реальные фотографии товаров на светлых плашках.

## Что внутри

- **6 категорий:** спиннинги, катушки, лески и шнуры, удилища, приманки, аксессуары.
- **Реальные бренды и цены** — Graphiteleader, Shimano, Daiwa, Kosadaka, Петроканат
  и др., по реальному рынку РФ (в рублях).
- **Реальные фото** товаров из папки `assets/img/` (спиннинги, катушки, лески).
  Для товаров без фото — фирменная тёмно-зелёная заглушка (карточка не «ломается»).
- **Функционал:** живой поиск, фильтр по категориям, сортировка (цена/рейтинг),
  карточка товара с характеристиками (модалка), корзина с сохранением в
  `localStorage` и оформлением заказа.
- Полностью адаптивная вёрстка (десктоп / планшет / телефон).

## Структура

```
index.html        — разметка страницы
css/style.css     — стили и адаптив (палитра в :root)
js/products.js    — каталог: категории и товары (цены, характеристики, фото)
js/app.js         — логика: поиск, фильтры, корзина, модалка
assets/img/       — фотографии товаров + README со списком «есть / нужно»
```

## Как запустить

Статический сайт, сборка не нужна. Открыть `index.html` в браузере или поднять
любой статический сервер:

```bash
python3 -m http.server 8000   # затем открыть http://localhost:8000
```

## Как добавить фото к товару

1. Положите картинку в `assets/img/` (например `lu-01.jpg`).
2. В `js/products.js` у нужного товара добавьте поле `img: 'lu-01.jpg'`.
   Готово — фото появится в карточке, корзине и модалке.

Полный список «какие фото уже есть и какие нужны» — в `assets/img/README.md`.
