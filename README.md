# 🎣 Клёвое место — рыболовный магазин-каталог (Санкт-Петербург)

Сайт-каталог рыболовных снастей. Пользователь выбирает удочку, спиннинг, катушку,
воблер или другую снасть, изучает характеристики и оформляет заказ. Магазин
находится в **Санкт-Петербурге** (Лиговский пр-т, 50).

## Что внутри

- **6 категорий:** спиннинги, удилища, катушки, приманки (воблеры/блёсны/силикон),
  лески и шнуры, аксессуары.
- **Реальные бренды и цены** — Shimano, Daiwa, Favorite, Rapala, Mepps, Power Pro
  и др., ориентированные на реальный рынок РФ (в рублях).
- **Реальные фото** снастей: карточки подгружают настоящие фотографии по ключевым
  словам (сервис loremflickr → Flickr). Если сеть недоступна — аккуратная
  SVG-заглушка, карточка не «ломается».
- **Функционал:** живой поиск, фильтр по категориям, сортировка (цена/рейтинг),
  карточка товара с характеристиками (модалка), корзина с сохранением в
  `localStorage` и оформлением заказа.
- Полностью адаптивная вёрстка (десктоп / планшет / телефон).

## Структура

```
index.html        — разметка страницы
css/style.css     — стили и адаптив
js/products.js    — каталог: категории и товары (цены, характеристики, фото)
js/app.js         — логика: поиск, фильтры, корзина, модалка
```

## Как запустить

Статический сайт, сборка не нужна. Достаточно открыть `index.html` в браузере
или поднять любой статический сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

> Для загрузки реальных фотографий нужен доступ в интернет (loremflickr.com).

## Как добавить товар

Откройте `js/products.js` и добавьте объект в массив `PRODUCTS`:
укажите категорию (`cat`), бренд, название, цену `price` (и старую `old` для скидки),
рейтинг, наличие `stock`, ключевые слова `photo` для фото и `specs` с характеристиками.
